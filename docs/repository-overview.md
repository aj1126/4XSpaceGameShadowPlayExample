# Repository Overview

This repository contains a Unity 3D C# tutorial project for building a 4X space game.

## Main folders

- `4X Space Game/`  
  The main playable Unity project and current project state.
- `Scripts/`  
  Tutorial progression snapshots, organized by tutorial part.
- `README.md`  
  Top-level repository entry point.

## Key technologies

- **Game engine:** Unity
- **Programming language:** C#
- **Unity version:** `2018.1.1f1`
- **Package system:** Unity Package Manager (`4X Space Game/Packages/manifest.json`)
- **UI and rendering:** Unity UI + TextMeshPro package references

## Unity project layout

Inside `4X Space Game/`:

- `Assets/` game content (scenes, prefabs, materials, sprites, scripts, data)
- `Packages/` package manifest and lock data
- `ProjectSettings/` Unity editor and project settings
- `4X Space Game.sln` and generated `.csproj` files for C# tooling integration

## Important game assets

- Scene: `4X Space Game/Assets/Scenes/GameScene.unity`
- Prefabs: `4X Space Game/Assets/Prefabs/`
- Data files: `4X Space Game/Assets/Data/Name_Lists/Systems/starNames1.txt`
